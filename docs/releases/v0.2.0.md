# AdventureTinyLLM v0.2.0 — Tactical RL + AIAdventureRPG Unity Example

Release date: **2026-11-02**
Previous release: **v0.1.0**, preserved without retagging or replacing old assets.

## What changed

AdventureTinyLLM is a tiny **51-feature PyTorch Transformer** capable of observing and acting inside a real Unity game. This release integrates a state-dependent survival/combat reward policy and provides the **actual AIAdventureRPG Unity gameplay module** as a separate example archive.

### Tiny AI and training

- **Schema v4 / 51 numerical observations** and protocol **`explicit-action-id-v5-tactical`**. New features encode combat detection, low HP/MP overlays, hostile range and direction, attack windup and visible thorn proximity.
- Five trainable action heads: movement direction, interaction, NPC response, movement distance, and combat ability. Movement-gradient credits **both direction and distance**; ability is masked if MP/HP conditions prevent its use.
- Finite-distance movement; hard-boundary legal-action masks and anti-stuck movement safeguards; observation does not reveal hidden berry poisoning or future outcomes.
- Explicit one-time `action_id` and `POST /experience` after the game reports actual outcomes. Only **TRAIN TINY** may update weights; **USE TRAINED** uses frozen inference.
- Source model checkpoints for 32/40/43-input versions are **not compatible** with v4 and are not bundled. Keep any older trained checkpoints in `checkpoints/legacy`; a compatible 51-input checkpoint can be trained or resumed separately.
- Sign reading through `POST /observe` is zero-reward **information only**, not a neural update.

### Combat, magic and context-dependent rewards

- **Normal attack**: 14 damage, 0 MP, only slight sparks/dust.
- **Special**: 32 damage, 12 MP, purple light/ring/smoke; **Arc Pulse**: 26 per enemy in 5.3 units, 20 MP; **Heal**: +30 HP for 25 MP; zero MP means skills unavailable.
- **Combat detection** is an omnidirectional 9-unit radius (XZ), with a 1.5-second grace to leave combat. Separate **LOW HP** and **LOW MP** flags use configurable 20% thresholds.
- Boars visibly wind up strikes. Real evasion gets positive reward when movement escapes attack range. A previously seen thorn avoided without contact also gets positive reward.
- **Kill +1.45**, hit +0.25, skill hit +0.30, dodged committed strike +0.35, avoided seen thorn +0.28. Misses, empty skill casts, wasted recovery, damage under critical HP and death **−2.00** are penalized. Actual HP/MP deltas and pre-event thresholds determine final scores.
- **Ollama mode** receives structured HP/MP and combat context. **RESET OLLAMA CONTEXT** clears prior persisted context and cancels pending calls without resetting game state or Tiny weights.

**Unity sample limitation:** the snapshot is **not a standalone Unity project**. It requires the original HMGF.Core, HMGF.World and HMGF.Presentation assemblies available in the user's original Unity project. No City Builder changes or proprietary Unity engine binaries are included. Do not expect an empty Unity project to compile the example without those dependencies.

## Quick start

```powershell
# From AdventureTinyLLM source root, Python 3.11+ and compatible PyTorch
python -m venv .venv
.\.venv\Scripts\python.exe -m pip install -e ".[api,dev]"
.\.venv\Scripts\python.exe -m pytest
powershell -ExecutionPolicy Bypass -File .\scripts\start_api.ps1 -EnableOnline
```

Confirm `http://127.0.0.1:8765/health` is ready with 51 observations. Open the provided Unity module **inside a Unity 6 project already containing the HMGF dependencies**, load `Assets/AIAdventureRPG/Scenes/AdventureValley.unity`, and select **TRAIN TINY**, **USE TRAINED**, **OLLAMA**, or **MANUAL**. See the example README for controls.

## Compatibility and caveats

This is an experimental one-step actor-critic policy, not PPO or a pretrained language model; there is no multi-step causal return attribution or verified autonomous combat proficiency. Loopback-only API; no authentication for remote access. Explicitly evaluate with repeated game episodes before claiming learning improvements.
