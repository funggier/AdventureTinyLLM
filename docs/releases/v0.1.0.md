# AdventureTinyLLM v0.1.0 — Initial Prototype

Date: 2026-11-01
License: MIT
Visibility: public
Repository: https://github.com/funggier/AdventureTinyLLM

## Purpose

This release freezes the first small, random-initialized Transformer engineering prototype for a future independent Tiny AI in the Unity game AIAdventureRPG.

The idea combines selected *engineering patterns* from FlyWireLLM (RMSNorm, RoPE, grouped-query attention, SwiGLU, deterministic initialization) with future *cognitive experiments* inspired by ProjectASCA (familiarity, episodic memory, surprise, bounded action/outcome loops).

No Ollama supervision, imitation data, shared Ollama memory, pretrained weights or ML-Agents dependency is included.

## Included

- Two-layer temporal causal Transformer, d_model=64, 4 query heads, 2 KV heads, 32 observation features and up to 32 observations of context.
- Factorized movement/interact/answer policy heads, plus a scalar value head.
- 95,567 parameters for the tracked Tiny-64 model.
- MIT License, Thai background document, architecture, roadmap, API contract, source and tests.
- Three loopback REST endpoints: GET /health, POST /act and POST /reset.
- Model reports trained=false and training_available=false; no training endpoints.

## Getting started

Use Python 3.11+ and install PyTorch. On a Windows machine using uv:

~~~powershell
uv venv --python 3.11 .venv
$env:UV_CACHE_DIR = 'T:\Space\Caches\uv-adventuretinyllm'
uv pip install --python .venv\Scripts\python.exe torch --index-url https://download.pytorch.org/whl/cpu
uv pip install --python .venv\Scripts\python.exe -e '.[api,dev]'
.\.venv\Scripts\python.exe -m pytest
.\.venv\Scripts\python.exe -m uvicorn adventure_tiny_llm.api:app --host 127.0.0.1 --port 8765
~~~

Then open http://127.0.0.1:8765/health. The /act input schema is in docs/API_CONTRACT.md.

Do not expose the local development API to an untrusted network.
