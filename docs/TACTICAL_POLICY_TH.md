# Tiny AI v4 — Tactical Combat / Context Reward (2026-11-02)

โมเดลนี้เป็น PyTorch Transformer ขนาดเล็ก ฝึกจากเหตุการณ์จริงใน Unity ไม่ใช่โมเดลภาษา และไม่รับรู้ผลลัพธ์ล่วงหน้าผ่านข้อมูล hidden state

## รูปแบบข้อมูลใหม่

- `schema_version=4`, `observation_size=51`
- REST `action_protocol=explicit-action-id-v5-tactical`
- 43 ตัวแรกยังเป็นการเคลื่อนที่ การมองเห็น สถานะ HP/MP ความเบื่อ และความพร้อมใช้สกิลตามเวอร์ชันก่อนหน้า
- 8 ตัวใหม่ `43..50`: COMBAT, LOW HP, LOW MP, ระยะมอนสเตอร์ภายในวงตรวจจับ, ทิศ X/Z มอนสเตอร์, การเตรียมโจมตี, ระยะหนามที่มองเห็นจริง
- `/act` ยังเลือกทิศทาง ระยะเดิน โต้ตอบ คำตอบ NPC และสกิล และคืน `action_id` สำหรับบันทึกเครดิตครั้งเดียว
- `/experience` เท่านั้นที่อัปเดตน้ำหนักในโหมด Train; `/observe` อ่านป้ายเป็นข้อมูลแต่ไม่มีการฝึกจากการอ่านโดยตรง
- API ใช้ action mask ไม่ให้เลือกทิศที่ชนขอบแผนที่ง่าย ๆ หรือสกิลที่ MP ไม่พอ

## การให้รางวัล

สูตรอยู่ในโปรเจกต์ Unity ที่ `Assets/AIAdventureRPG/Runtime/AdventureRewardPolicy.cs` โดยยึดความเปลี่ยนแปลงของสถานะจริงพร้อมค่าก่อนเกิดเหตุการณ์ และใช้เหตุการณ์โจมตี/หลบหลีกที่ตรวจสอบได้ คะแนนสรุปเริ่มต้น: ฆ่ามอนสเตอร์ +1.45, โจมตีปกติโดน +0.25, สกิลโจมตีโดน +0.30 ต่อเป้าหมาย (โบนัสจำกัด), หลบการโจมตีที่เริ่มฟันแล้ว +0.35, เห็นหนามและเดินหนีจริง +0.28, โจมตีพลาด −0.20, สกิลใช้ไม่ได้ −0.13, ตาย −2.00

เสีย HP ตอนเหลือต่ำกว่า 20% จะได้รับค่าลบมากขึ้น ขณะที่ฟื้น HP/MP ตอนต่ำกว่า 20% จะได้โบนัสมากขึ้น ส่วนเก็บของตอนค่าเต็มจะได้คะแนนลบ เพราะไม่ได้เพิ่มค่า HP/MP จริง ๆ

## การจัดเก็บน้ำหนักเดิม

โมเดล 43 features รุ่นก่อนเก็บไว้ที่ `checkpoints/legacy/tiny-unity-pre-tactical-v3-43features-2026-11-02.pt` และไม่ถูกเขียนทับ โมเดลปัจจุบันใช้ input projection ขนาด 51 ซึ่งไม่เข้ากันกับ checkpoint รุ่นเดิม จึงเริ่มน้ำหนักสุ่มใหม่โดยเก็บ checkpoint ออนไลน์ใหม่ที่ `checkpoints/tiny-unity-online.pt`

เริ่มเซิร์ฟเวอร์ด้วย `scripts/start_api.ps1 -EnableOnline` และเรียก `GET http://127.0.0.1:8765/health` เพื่อตรวจสถานะ จาก Unity เลือก TRAIN TINY เพื่อฝึก หรือ USE TRAINED เพื่อใช้เฉพาะการอนุมานโดยไม่ส่งรางวัลใหม่

## ข้อจำกัด

โมเดลยังต้องใช้การฝึกจำนวนมากกว่าจะมีพฤติกรรมหนีอันตรายและบริหาร HP/MP อย่างชาญฉลาด ผลตรวจ API ว่าตอบสำเร็จหรือมีจำนวน training updates ไม่ถือว่าเป็นหลักฐานว่านโยบายเรียนรู้การต่อสู้ได้ดีแล้ว
