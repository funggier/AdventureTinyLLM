# ที่มาและแนวคิดของ AdventureTinyLLM

## ทำไมจึงสร้างโปรเจคนี้

เริ่มจากการทดลอง AI ในเกม Unity ที่ชื่อ AIAdventureRPG ซึ่งมีแผนที่ Voxel และการสำรวจโลก ตัวละครพบหนามแล้วเสีย HP พบสมุนไพรแล้วฟื้น HP และพบ NPC ที่ต้องหันหน้าให้ถูกก่อนพูดคุยและตอบคำถาม

เดิมมีโหมดผู้เล่นและ Ollama ควบคุมผ่าน API แต่เราต้องการเปรียบเทียบกับ AI ที่ **เริ่มจากน้ำหนักสุ่มและเรียนรู้จากการลงมือทำเองจริงๆ** โดย Ollama ไม่เป็นครู ไม่ส่งคำตอบและไม่แบ่งปันความจำให้ Tiny AI

จึงแยกสร้าง **AdventureTinyLLM** เป็นโปรเจค Transformer จิ๋วเพื่อใช้งานกับเกมผ่าน API แทนการฝังระบบฝึกไว้ใน Unity

## แนวคิดจากโครงการที่เคยทำ

- **FlyWireLLM:** เรียนรู้แนวทางสร้าง Transformer จากศูนย์ด้วยการกำหนดโครงสร้างชัดเจน เช่น RMSNorm / RoPE / GQA / SwiGLU รวมถึงการจัดการ Seed, Checkpoint, การฝึก และการทดสอบแบบตรวจสอบย้อนหลังได้
- **ProjectASCA:** นำแรงบันดาลใจจาก Familiarity, Surprise/Uncertainty, Episodic Memory, Procedural Memory, Selective Recall และวงจรตรวจผลการกระทำ โดยไม่จำเป็นต้องยกทั้งระบบมาใช้
- **AIAdventureRPG:** เป็นโลกทดลองสำหรับการมองเห็น ตำแหน่ง การกระทำ และผลตอบแทนจริงจากเกม

แนวคิดที่นำมาประยุกต์ไม่เท่ากับการคัดลอกโค้ดหรือความสามารถทั้งหมดของแต่ละโปรเจค ส่วนที่ยังไม่พัฒนาจะระบุว่าเป็นแผน ไม่กล่าวอ้างว่าใช้งานได้แล้ว

## เป้าหมายหลัก

1. เริ่มจาก Transformer ขนาดเล็กมากที่ไม่มีน้ำหนักฝึกมาก่อน
2. ใช้ข้อมูลเชิงโครงสร้างจากตัวละคร เช่น พิกัด ทิศทาง HP และสิ่งที่มองเห็น แทนการใช้ LLM ภาษาเต็มรูปแบบ
3. เรียนรู้จากผลที่เกมรายงานหลังปฏิสัมพันธ์ (เช่น +26 HP / -18 HP) โดยไม่อ่านกฎลับล่วงหน้า
4. บันทึกน้ำหนักและความจำของ Tiny AI แยกจาก Ollama อย่างเด็ดขาด
5. ใช้ REST API ให้ Unity เรียกใช้การตัดสินใจ พร้อมต่อยอดระบบฝึกแยกจากเกม
6. ทดลองการฝึก Native RL ก่อน โดยมี ML-Agents เป็นอะแดปเตอร์เสริมในอนาคต

## สิ่งที่อยากทดลองในอนาคต

- Tiny Transformer ที่มี Context ระยะสั้น เทียบกับรุ่นที่มี Episodic Memory
- การเพิ่ม Surprise เมื่อผลจริงไม่ตรงกับที่คาด
- การสร้าง Skill จากลำดับการกระทำที่เคยสำเร็จ
- ฝึกใน Training Arena แบบเร็ว แล้วทดสอบในโลก Adventure Valley ที่ไม่เคยใช้ฝึก
- เปรียบเทียบประสิทธิภาพกับ Ollama แต่ไม่ถ่ายทอดความรู้ระหว่างกัน

**ข้อจำกัด:** ปัจจุบัน Repo รุ่นเริ่มต้นเน้นโครงสร้างและ Inference ของโมเดลที่ยังไม่ฝึก การฝึก Reinforcement Learning และการเชื่อม Unity Tiny API จะทำเพิ่มในระยะถัดไป
